# Fashion ERP Mobile

Android + iOS app (React Native / Expo, planned) for employees of companies using the Fashion ERP. Version 1: login, attendance, anti-fake attendance.

**Status:** documentation and Phase 0 feasibility only — no app code yet. See `docs/14_MOBILE_PROJECT_STATUS.md`.

- Backend: the existing Fashion ERP (`fashion-erp` repo, GitHub `TeamsIndradhar/fashion-erp`), production `https://erp.indradhar.in/`. This repo has no database or backend of its own.
- Start here: `docs/00_PROJECT_OVERVIEW.md`, then `docs/12_DECISION_LOG.md` and `docs/11_IMPLEMENTATION_ROADMAP.md`.
- AI agents: read `docs/13_AI_AGENT_WORKFLOW.md` before any work.
