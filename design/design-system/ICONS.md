# Icons (Design System v1.0)

- 24 px outline icons (Lucide style, 2 px stroke) inside a **rounded icon tile** (44 × 44, radius 12) tinted ~12 % of the icon colour — like the reference module grid.
- App: `lucide-react-native` or Expo vector icons (Phase 2, dependency to approve). Prototype: inline SVG equivalents.
- Icon colour follows meaning, not module: primary (navigation), success (done / in), danger (logout / reject), warning (pending / remark), info (help).
- Fixed status icons: check-circle (success) · alert-triangle (review) · x-circle (error) · lock (no permission) · wifi-off (offline) · map-pin (location) · shield-check (verified).
- Bell shows an unread badge (red, `micro`, "99+" max).
- Brand mark: the hanger logo from the references (outline, `primary`).
